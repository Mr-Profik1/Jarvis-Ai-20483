# Jarvis — голосовой ассистент для ПК

Слушает микрофон. Скажи «Джарвис» — окно всплывает поверх всего, дальше говори команду:

- «Джарвис, включи игровой режим» — макрос из `macros.json`
- «Джарвис, исправь ошибку в приложении» — смотрит экран, читает код, правит файлы
- «Джарвис, как запустить проект?» — отвечает голосом

Умеет: скриншот экрана, мышь, клавиатура (в том числе русский текст), команды shell, запуск программ,
чтение и запись файлов, поиск в интернете, чтение ссылок. Отвечает голосом.

## Режим без ключа (мини-мозг)
Если при первом запуске нажать «Отмена» вместо ключа, Jarvis работает без ИИ и почти ничего не весит:
- **Макросы** из `macros.json` («игровой режим»). Мини-мозг понимает фразы с ошибками и своими словами:
  «игравой режим», «давай поиграем», «хочу играть». Для этого в макросе есть `aliases` и `examples`.
- **Простые команды:** время, дата, скриншот, «открой ютуб», «открой блокнот», «что ты умеешь».
- Умные команды («исправь ошибку», «как запустить») без ИИ недоступны. Чтобы включить их,
  добавь `ANTHROPIC_API_KEY=...` в `.env` и удали файл `.no_key`.

### Свой игровой режим (VPN и игры)
Открой `macros.json` и допиши в `commands` свои запуски, например:
`"start \"\" \"C:\\Program Files\\MyVPN\\vpn.exe\""`, `"start \"\" steam://rungameid/ID_ИГРЫ"`.
Включится ли VPN самой командой, зависит от самого VPN-клиента: нужна его консольная команда или ярлык.

## Запуск
1. `pip install -r requirements.txt`
2. Скопируй `.env.example` в `.env`, впиши `ANTHROPIC_API_KEY`.
3. `python jarvis_desktop.py`

## Управление
- «Джарвис, стоп» или кнопка «Стоп» — прервать задачу. Мышь в угол экрана — аварийная остановка.
- Команды, запуск программ и запись файлов подтверждаются окном «Да/Нет».
- Крестик окна только прячет его, выйти можно кнопкой «Выход».
- Команду можно напечатать в поле внизу окна.

## Макросы
`macros.json`: имя, `aliases`, список `commands`, фраза `say`. Команды по умолчанию для Windows.
Макросы выполняются без подтверждения, потому что ты сам их прописал.

## Сборка exe (на Windows)
`pip install pyinstaller` и `pyinstaller --onefile --noconsole jarvis_desktop.py`.
Рядом с exe положи `.env` и `macros.json`.

## Безопасность
Ассистент видит твой экран и файлы. Не публикуй `.env`. Если рядом кто-то скажет «Джарвис», он начнёт действовать.
Распознавание речи идёт через бесплатный Google Speech, нужен интернет.
