# OpenJarvis на Windows

Это копия проекта [open-jarvis/OpenJarvis](https://github.com/open-jarvis/OpenJarvis) (лицензия Apache 2.0, файл `LICENSE` лежит рядом) с запуском в один клик.

## Как запустить
1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте папку `openjarvis\windows` и дважды щёлкните `start.bat`.

При первом запуске он сам:
- поставит `uv` (он сам скачает нужный Python),
- поставит Ollama,
- скачает модель (по умолчанию `llama3.2:1b`, около 1,3 ГБ, подходит для 4 ГБ ОЗУ),
- установит OpenJarvis и запустит `jarvis`.

Все следующие запуски пропускают уже сделанное и стартуют быстро. Нужен интернет и около 3-4 ГБ свободного места.

## Другая модель
Впишите её имя в файл `windows\model.txt` (одна строка), например `qwen3:1.7b` (лучше понимает русский) или `qwen3:4b` (нужно от 8 ГБ ОЗУ). При следующем запуске она скачается и станет моделью по умолчанию.

## Если что-то не работает
- Окно закрылось сразу: запустите `start.bat` ещё раз, читайте сообщение об ошибке.
- Не ставится Ollama: поставьте вручную с https://ollama.com/download и запустите `start.bat` снова.
- Расширение на Rust (память и часть защитных функций) не собирается автоматически, для базового чата оно не нужно.

Ваш собственный Jarvis из корня репозитория (`jarvis_desktop.py`, `start.bat`) эта папка не затрагивает.
